# DESIGN SYSTEM & COLOR PALETTE RULE (.agents/rules/design.md)

Tài liệu này định nghĩa hệ thống màu sắc, phông chữ, và quy tắc thiết kế cố định cho dự án. Mọi thay đổi về giao diện Frontend phải tuân thủ nghiêm ngặt các giá trị dưới đây:

## 1. Color Tokens (Bảng màu cố định)
- **Primary Navy**: `#022448` (`bg-primary`, `text-primary`)
- **Primary Container**: `#1e3a5f` (`bg-primary-container`, `text-primary-container`)
- **Secondary Interactive Blue**: `#0051d5` (`bg-secondary`, `text-secondary`)
- **Tertiary Deep Teal**: `#002926` (`bg-tertiary`, `text-tertiary`)
- **Tertiary Container**: `#00413c` (`bg-tertiary-container`)
- **Canvas Background**: `#f8f9ff` (`bg-background`, `bg-surface`)
- **Surface Lowest (Card White)**: `#ffffff` (`bg-surface-container-lowest`)
- **Surface Low**: `#eff4ff` (`bg-surface-container-low`)
- **Surface High**: `#dce9ff` (`bg-surface-container-high`)
- **Text Main**: `#0b1c30` (`text-on-surface`)
- **Text Muted / Sub**: `#43474e` (`text-on-surface-variant`)
- **Status Success**: `#166534` trên nền `#DCFCE7`
- **Status Warning**: `#92400E` trên nền `#FEF3C7`
- **Status Danger**: `#991B1B` trên nền `#FEE2E2`
